# ForeverPilot

Аддон-советник для **World of Warcraft: Forever** (клиент 1.60.1, Interface 16001, тип игры `camelot`).

Анализирует персонажа и отвечает на один вопрос: **что выгоднее всего сделать прямо сейчас.**
Что скрафтить, что купить, что надеть, что зачаровать, что продать, что распылить.

Аддон ничего не делает за игрока. Покупки, продажи, крафт и зачарование выполняет только человек.

---

## Что он умеет

**Персонаж.** Читает класс, уровень, специализацию, надетые вещи и чары на них, сумки, банк,
профессии, выученные рецепты и золото. Данные о персонаже берутся из клиента и всегда свежие.

**Крафт.** Раскладывает рецепт до базовых материалов через все промежуточные ступени, вычитает
запасы из сумок и банка, считает недостающее. Учитывает выход за один крафт, общий ингредиент
в нескольких рецептах и защиту от циклических зависимостей. Сравнивает «изготовить самому»
против «купить готовым».

**Экипировка.** Система весов характеристик с профилем под специализацию. Отдельно то, что можно
надеть сейчас, и отдельно то, что надеть нельзя — последнее уходит в ветку «изготовить на продажу».
Совет, снижающий главную характеристику, не выдаётся как улучшение ни при каком итоговом плюсе.

**Чары.** Раскладка по слотам из `categoryID` рецептов клиента. Только выученные формулы.
Предмет для слота ищется и в сумках тоже — инструмент профессии в руке не считается оружием.

**Экономика.** Прибыльный крафт, арбитраж у торговцев с координатами, распыление, перепродажа.
К каждому денежному совету прикладывается оценка риска: требуемый капитал, риск отсутствия
покупателя, риск цены, максимальный убыток.

**Цены.** Через Auctionator. Возраст каждой цены виден. Аддон копит собственные суточные слепки
рынка и сравнивает живую цену с историей: выброс заменяется медианой, а не выдаётся за рынок.
Без Auctionator аддон работает, помечая цены как неизвестные.

**Навигация.** Собственная стрелка на цель с расстоянием. Четыре состояния: стрелка, компас при
недоступном направлении взгляда, текстовые координаты при цели в другой зоне, гашение по прибытии.

**Самодиагностика.** Пишет в SavedVariables воронку потерь по каждой ветке, причину любого нуля,
журнал решений по ценам, список недостающих данных и читаемую сводку по-русски. Команда `/fp diag`.

## Установка

Скопировать папку `ForeverPilot` в `Interface\AddOns\` установки игры. Включить в списке аддонов.

Открывается командой `/fp` или кнопкой у миникарты.

**После первого входа откройте по разу окно каждой профессии** — до этого клиент не отдаёт
рецепты вовсе, и аддон об этом честно скажет карточкой наверху списка.

### Необязательные соседи

Работает и без них, но с ними лучше:

- **Auctionator** — цены и список покупок
- **Syndicator** — инвентарь других персонажей, банк, золото
- **Polestar** — характеристики предметов и координаты NPC
- **Mastercraft**, **QuestieDB**, **TomTom**

Каждое обращение к чужому аддону проходит проверку существования: если его нет, ветка молчит
и говорит почему, а не падает.

## Команды

| Команда | Что делает |
|---|---|
| `/fp` | открыть окно |
| `/fp panel` | показать или убрать панель текущего шага |
| `/fp show` | вернуть все скрытые советы |
| `/fp undo` | вернуть последний скрытый |
| `/fp diag` | краткая сводка самодиагностики |
| `/fp diag full` | подробности в чат |
| `/fp reset` | вернуть окно, панель и стрелку на место |

## Разработка

Код: `Core/` — основа и слой доступа к API, `Logic/` — вся бизнес-логика, `UI/` — интерфейс,
`Data/` — таблицы данных, `Tests/` — проверки.

Бизнес-логика отделена от интерфейса и от прямых вызовов игрового API. Каждое обращение к клиенту
идёт через `Core/Api.lua`.

**Язык: Lua 5.1.** Клиент не понимает синтаксис 5.2 и новее. `Tests/dialect.lua` ищет такое
лексически, потому что проверка через LuaJIT пропускает `goto` и прочие расширения — на этом
один раз уже обожглись, и весь модуль молча не грузился.

Тесты гоняются через `texluajit` и через настоящий PUC Lua 5.1:

```
lua Tests/run.lua          # офлайн
lua Tests/run.lua real     # на реальных SavedVariables
python3 Tests/mutate.py    # мутационная проверка
```

Фикстуры выводятся из реально установленных баз, а не из выдуманных значений: набор, построенный
на сочинённых данных, несколько раз оказывался зелёным при сломанном коде.

## Происхождение данных

Код в этом репозитории написан с нуля. Кода других аддонов в нём нет.

**Но файлы в `ForeverPilot/Data/` — другое дело.** Это игровые данные, извлечённые из баз,
которые идут в составе других аддонов:

| Файл | Откуда |
|---|---|
| `ForeverSource.lua` | таблицы Mastercraft (`VendorData`, `TrainerData`, `RecipeData`), выборочно сверено с Wowhead Forever |
| `Horizon.lua` | Mastercraft `RecipeData`/`ItemData`, Polestar_Codex, пороги сверены с WhatsTraining; экономика Merchant's Favor прочитана с theforeverguides.com |

Происхождение каждой таблицы указано в шапке соответствующего файла.

Для личного использования это не имеет значения. **Для публичного репозитория — имеет**: у Polestar
лицензия GPL-3.0, мейнтейнеры QuestieDB просят считать свои данные all-rights-reserved, у Mastercraft
файла лицензии нет вовсе. Прежде чем делать репозиторий публичным, решите, что делать с `Data/`:
заменить на собственный сбор по ходу игры, либо получить разрешение, либо оставить репозиторий закрытым.

Лицензия MIT в `LICENSE` распространяется на **код**, не на эти данные.

## Чего он не делает

Не покупает, не продаёт, не крафтит, не зачаровывает и не управляет персонажем. Вообще.
Это осознанное ограничение, а не недоделка: аддон только считает и советует.
